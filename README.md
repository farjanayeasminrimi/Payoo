# PAYOO - Smart MFS Interface

PAYOO is a simple and user-friendly Mobile Financial Services (MFS) application that simulates basic digital banking operations. It allows users to manage money, perform transactions, and track their financial activities in one place through a clean and intuitive interface.

The platform is designed to provide a smooth and realistic digital payment experience where users can easily add money, cash out, transfer funds, and view their transaction history with secure and structured workflows.

## Key Features

### Secure Login System
Users can log in using a phone number and PIN to access their account securely.

### Dashboard Overview
A clean dashboard displays the current balance and provides quick access to all financial services.

### Add Money
Users can add funds to their account and instantly see the updated balance.

### Cash Out
Users can withdraw money securely with PIN verification to ensure safe transactions.

### Money Transfer
Users can send money to other accounts quickly and easily with proper validation.

### Bonus Rewards
Users can receive and track bonus rewards within their account.

### Transaction History
All transactions are saved so users can easily track their financial activities.

### PIN Security
Every important action requires PIN verification for secure and reliable transactions.

### Responsive Design
The interface works smoothly across mobile, tablet, and desktop devices.
